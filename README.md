# СЭМИАМ НЭПСЭК · АРХИВ 003

![Превью сайта](preview.png)

**3D-версия:** https://juneaucross.github.io/nepsack-scene/

**Классическая версия:** https://juneaucross.github.io/nepsack/

Интерактивное досье персонажа D&D 5e, собранное по листу
`charSheet.html`: халфлинг-плут 3 уровня, 66 лет, стеклянный глаз,
две ячейки заклинаний и ноль сожалений.

Сайт задуман как **оккультный терминал**: закрытое дело, изъятое из
архива, которое одновременно является рабочим листом персонажа.
В 3D-версии hero превращён в кинематографичную сцену: три кости
падают на арену, сталкиваются, отскакивают и замирают над sigil-кругом,
а камера проходит три акта — «Падение», «Схватка» и «Приговор».
Вдохновение — тёмная «терминальная» типографика [qu.ai](https://www.qu.ai/),
но вся графика, эффекты и логика написаны с нуля.

## Запуск

Сайт полностью автономен: шрифты встроены, внешних запросов нет.

1. **Просто открыть** `index.html` двойным щелчком (работает по `file://`).
2. Или поднять локальный сервер:

   ```bash
   cd nepsack
   python3 -m http.server 4173
   ```

   и открыть <http://127.0.0.1:4173>.

Рекомендуется Chrome / Edge / Safari / Firefox последних версий.
WebGL желателен, но при его отсутствии включается статичный фон.

## 3D-сцена

- **Scroll = время.** Сцена не анимируется сама по себе: прогресс
  скролла внутри hero — единственный источник времени. Назад — сцена
  проигрывается назад, кадр в кадр.
- **Детерминированная физика.** Траектории d20, d8 и d4 считаются
  заранее фиксированным шагом 120 Гц: гравитация, контакт с полом,
  импульсы, трение, столкновения костей и «магические» импульсы.
  В кадр попадает интерполяция готовой временной шкалы; случайности
  в рантайме нет.
- **Три акта.** «Падение» — тёплый обсидиан и угли; «Схватка» —
  холодный бирюзовый свет; «Приговор» — кроваво-золотой портал.
  Цвет тумана, свет, руны на полу, спицы и портал перетекают между
  актами.
- **Камера.** Catmull-Rom-путь с разными планами: широкий вход,
  низкая траектория, орбита, финальный отъезд. Тряска при ударах
  тоже привязана к скроллу.
- **Рендер.** WebGL2: MSAA нет — высокий DPR и filmic composite;
  half-res bloom, инстансированные обелиски, аддитивные ауры,
  искры и угли, туман, блики и хроматическая аберрация.
- **Плавность.** Скролл сглаживается экспоненциальным фильтром,
  сцена рисуется только когда hero в кадре; DPR и число частиц
  зависят от мобильного тира. `prefers-reduced-motion` оставляет
  статичный финальный кадр.

## Интерактив

- **d20** — настоящий трёхмерный икосаэдр на canvas: вращение,
  кватернионная посадка нужной гранью к камере, критические успехи и
  провалы, журнал бросков. Кнопка «Везучий» появляется только при
  натуральной единице.
- **Навыки** — клик по строке открывает бросок с модификатором из листа;
  поиск и фильтр по характеристике.
- **Хиты** — кнопки ±1/±5, статусы «ранен / критически / без сознания»,
  долгий отдых, спасброски от смерти. Состояние сохраняется в
  `localStorage` и переживает перезагрузку.
- **Магия** — ячейки тратятся и восстанавливаются, карточки заклинаний
  раскрываются, «долгий отдых» возвращает всё.
- **Кольцо лечения** — 1d6 раз до отдыха.
- **Стеклянный глаз** — зрачок следит за курсором, глаз моргает;
  по клику — случайная фраза из городских слухов.
- **Командная палитра** — `⌘K` / `Ctrl+K`: разделы, навыки, заклинания,
  действия. На телефоне — кнопка с лупой.
- **Звук** — процедурный WebAudio (щелчки, броски, аккорды), по умолчанию
  выключен; кнопка в HUD.
- **Печать** — `ПЕЧАТЬ ДОСЬЕ` или `Ctrl/Cmd+P` собирает компактную
  светлую версию с раскрытыми заклинаниями и особенностями.

## Технологии

- **WebGL** — фрактальный фоновый шейдер (fbm, domain warping, угли,
  мышиный источник света) и отдельная WebGL2-сцена костей.
- **WebGL2 / GLSL ES 3.0** — собственный рендерер: инстансинг,
  процедурные руны и circuit-паттерны на обелисках, half-res bloom,
  ACES-тонмаппинг, портальный вихрь, аддитивные частицы.
- **Canvas 2D + собственная 3D-математика** — икосаэдр, проекция,
  кватернионы, сортировка граней, обратное отсечение.
- **Web Audio API** — синтезированные сигналы без аудиофайлов.
- **CSS** — container-less адаптив, `clip`, `backdrop-filter`,
  `mask`, `mix-blend-mode`, conic/radial-градиенты, `@media print`,
  `prefers-reduced-motion`.
- **JS** — IntersectionObserver, rAF-циклы, `dialog`, `<details>`,
  localStorage, делегирование событий.
- **Шрифты** — Unbounded, JetBrains Mono, Caveat; встроены в CSS
  data-URI, поэтому сайт работает офлайн и по `file://`.

## О данных

Все числа взяты из исходного листа: 11/11/8/17/15/15, +2 мастерства,
8 владений навыками, спасброски Ловкости и Интеллекта, 15 хитов,
КД 11, 25 фт, 3d8, 2150 XP, 9 см и 115 зм.

Бонусы в матрице отображаются **как в листе**: у владений `+2`,
у остальных `+0`. Ради интереса: по правилам 5e к ним следовало бы
прибавлять модификатор характеристики — сайт сознательно не «исправляет»
рукописный лист, а показывает его как артефакт. Имя игрока `ТЕКСТ`
из листа не переносилось.

## Доступность

Семантические разделы, один `h1`, ссылка «к содержимому», фокус-стили,
`aria-live` для результатов, клавиатурное управление диалогами,
`prefers-reduced-motion` (загрузка пропускается, эффекты замирают),
`<noscript>`-фолбэк. Пользовательский курсор отключается на тач-устройствах.
